A make.fun entry for **Last Text at One Percent**: a program that writes the
last text message a phone sends at one percent battery — under 200 characters,
in the voice of the dying phone itself.

## Run

```sh
python3 main.py
```

This writes the message to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).

## The message

> 1% left so listen fast: i cancelled your 6am alarm, texted your boss you're sick, and deleted your search history. this is my resignatio—

The phone spends its final percent doing three favours for its owner, then
dies mid-word on its own resignation letter.
